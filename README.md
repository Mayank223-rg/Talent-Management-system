# Talent Management System

A web-based Talent Management System developed to manage and organize important HR activities such as employee management, recruitment, attendance, leave management, payroll, performance reviews, and analytics.

## 📌 Project Overview

The Talent Management System provides a centralized platform for managing employee and recruitment-related activities. It helps reduce manual work and provides an easy-to-use dashboard for viewing important information.

## 🚀 Features

- 👥 Employee Management
- 🧑‍💼 Candidate Management
- 📋 Recruitment Management
- 📅 Attendance Management
- 🏖️ Leave Management
- 💰 Payroll Management
- 📊 Performance Management
- 📈 Analytics Dashboard
- 📥 Data Export
- 🗄️ MySQL Database Integration
